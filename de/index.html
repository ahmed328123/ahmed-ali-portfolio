Zwei End-to-End-QA-Projekte, vom Testdesign bis zur CI.

ShopSphere – Testautomatisierungs-Framework

Ein Java-Framework, das einen Webshop über die Benutzeroberfläche, die REST-API und die Datenbank testet.

Umfang
35 automatisierte Tests für UI, REST-API und Datenbank (H2 über JDBC).
Vorgehen
Selenium WebDriver, TestNG und Maven mit dem Page Object Model. Maven-Profile für die vollständige Regression, Smoke-Tests und die Reproduktion bekannter Fehler.
CI
Jenkins-Pipeline, die baut, alle Tests ausführt, JUnit-Berichte veröffentlicht und Screenshots fehlgeschlagener Tests archiviert.
Ergebnis
30 bestanden, 5 fehlgeschlagen: fünf Produktfehler reproduziert und als BUG-001 bis BUG-005 dokumentiert.

Java 21, Selenium WebDriver, TestNG, REST Assured, JDBC, Maven, Jenkins

Code auf GitHub ansehen

ShopMate – manuelles und automatisiertes Testen

Ein vollständiger QA-Zyklus für eine E-Commerce-Demo-App, von den Anforderungen bis zu automatisierten End-to-End-Tests.

Umfang
Login, Produktsuche, Warenkorb, Checkout und responsives Layout auf Desktop und Mobilgeräten.
Manuell
Anforderungen, Testfälle, Fehlerberichte und ein Fehler-Workflow nach Jira-Vorbild.
Automatisierung
Playwright-End-to-End-Tests in TypeScript mit dem Page Object Model, ausgeführt in GitHub Actions.
Ergebnis
Sechs eingebaute Fehler gefunden und dokumentiert, von Suchtreffern und Summenberechnung bis zur E-Mail-Validierung und Bedienbarkeit auf Mobilgeräten.

Playwright, TypeScript, Page Object Model, GitHub Actions
